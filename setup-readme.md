# Project Setup Guide

Update the frontend and backend, add environment variables, and run the project using the following steps:

- Update icons in `client/public`
- Update frontend config in `client/src/config.json`
- Update backend config in `config.json`
- Create a new `.env` file using `.env.dist` as reference

Then run the following commands in the project root:

```bash
npm i
npm run build
npm start
